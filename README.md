# 🚗 Smart Garage

## 📌 Описание на проекта

**Smart Garage** е пълнофункционално уеб приложение, предназначено за собственици на автосервизи. То позволява управление на клиенти, автомобили, извършени услуги и сервизни посещения. Проектът е разработен с Java и Spring Boot, следвайки най-добрите практики за архитектура, сигурност и документация на REST API.

---

## 🎯 Основна функционалност

- Регистрация и автентикация на потребители (служители/клиенти)
- Управление на превозни средства, клиенти и сервизни услуги
- История на посещения и извършени услуги за всяко превозно средство
- Генериране на PDF отчети и фактури
- Изпращане на автоматични имейли с профили и пароли
- Избор на валута и автоматично конвертиране на стойности
- Управление на заявки за работа, рейтинг на посещения, програма за лоялност, дистанционни посещения

---

## 🧰 Използвани технологии

- **Java 17**, **Spring Boot**
- **Spring Security**, **Spring Data JPA**
- **MariaDB
- **Swagger** за REST API документация
- **Lombok**, **Thymeleaf**, **iText** (или PDFBox)
